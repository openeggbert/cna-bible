\section{Reading this table safely}

Two cautions from Volume~I apply to every row above. First, ``verified'' means something
different for different backends --- Chapter~\ref{ch:direct3d-backends}'s own D3D9 column is
explicitly the strictest bar in the project (pixel-for-pixel against a real running XNA~4.0
runtime), while a BGFX or CANVAS row's own verification is scoped more narrowly, and each
backend chapter says so directly rather than leaving the reader to assume equivalence.
Second, this table is a snapshot. Volume~I's own source material carried dated corrections in
both directions --- the D3D9 backend's own documentation and the project's cross-backend
feature matrix genuinely disagreed about the render-target-as-texture fix's timing at one
point, and the feature matrix's own account was the more current one. Treat this appendix the
same way: a starting map, not a final word, to be checked against the project's own current
\texttt{docs/graphics-backend-feature-matrix.md} before relying on any single row.
